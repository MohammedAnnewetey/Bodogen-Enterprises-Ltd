BODOGEN ENTERPRISES LIMITED — MULTI-PAGE WEBSITE CONCEPT

Open index.html in a browser. All pages link to each other.
5 main pages + 8 service detail pages = 13 HTML pages.
Each page has its own CSS file in css/ and shared styling in css/common.css.
Mobile menu, service dropdown, reveal animations and email enquiry are handled by js/main.js.
All sector illustrations are locally created SVG assets in assets/ and can be replaced by real photos.
The supplied logo is in assets/bodogen-logo.jpg.
